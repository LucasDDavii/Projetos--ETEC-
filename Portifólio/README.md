## Descrição do projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal com o objetivo de apresentar meu perfil acadêmico, conhecimentos na área de Desenvolvimento de Sistemas, tecnologias estudadas e projetos desenvolvidos durante minha formação.

O site foi criado para organizar minhas informações de maneira clara e apresentar minha evolução como estudante e futuro profissional da área de tecnologia.

## Tecnologias utilizadas

As principais tecnologias utilizadas no desenvolvimento foram:

- **HTML5:** responsável pela estrutura e organização dos elementos da página.
- **CSS3:** utilizaddo para estilização e personalização visual do portfólio.
- **Bootstrap 5:** utilizado para facilitar a construção do layout, organização dos elementos e responsividade.
- **JavaScript:** utilizado com o Bootstrap para permitir o funcionamento dos componentes interativos, como o carrossel de imagens.

##  Funcionamento do projeto

O portfólio é dividido em seções que permitem ao visitante conhecer diferentes informações sobre meu perfil.

Entre as funcionalidades disponíveis estão:

- Apresentação pessoal e foto de perfil.
- Informações sobre minha formação em Desenvolvimento de Sistemas.
- Apresentação das tecnologias e ferramentas estudadas.
- Exibição de projetos desenvolvidos.
- Links para acessar os repositórios dos projetos no GitHub.
- Carrossel de imagens com navegação entre diferentes slides.

O layout utiliza recursos do Bootstrap para adaptar a organização dos elementos a diferentes tamanhos de tela, proporcionando uma navegação mais adequada em computadores e dispositivos móveis.

##  Novo recurso adicionado: Carrossel de imagens com transição suave

O novo recurso implementado foi um carrossel de imagens utilizando o componente Carousel do Bootstrap 5, com o efeito de transição suave conhecido como **Carousel Fade**.

Esse recurso permite apresentar diferentes imagens em uma mesma área da página, tornando a navegação mais dinâmica e melhorando a apresentação visual do portfólio.

##  Como o novo recurso foi implementado

A implementação foi realizada utilizando HTML e as classes e atributos disponibilizados pelo Bootstrap 5.

Foram utilizados os seguintes recursos:

- `carousel`: define o componente principal do carrossel.
- `carousel-fade`: adiciona o efeito de transição suave entre as imagens.
- `carousel-inner`: agrupa os slides do carrossel.
- `carousel-item`: representa cada imagem apresentada.
- `carousel-indicators`: cria indicadores que permitem selecionar diretamente cada slide.
- `carousel-control-prev` e `carousel-control-next`: permitem voltar ao slide anterior ou avançar para o próximo.

Também foi utilizado o atributo `data-bs-ride="carousel"` para iniciar a reprodução automática e o JavaScript Bundle do Bootstrap para habilitar o funcionamento das interações.

Dessa forma, o recurso foi integrado ao portfólio para proporcionar uma apresentação visual mais interativa e organizada.
