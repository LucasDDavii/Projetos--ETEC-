Consumo e preço de aparelhos por mês
Linguagem: [Python]
Usei Python por ser a linguagem que estou aprendendo além de ter uma linguagem simples

Fórmula usada no cálculo:
Consumo Mensal:
consumoMensal = (potencia * horasDia * 30) / 1000

potencia = Valor que o aparelho consome (informado pelo usuário)
horasDia = tempo que o usuário usa por dia (informado pelo usuário)
30 = tempo médio de um mês
1000 = valor usado para converter Wh para kWh
Preço
preco = consumoMensal * 0.75

Fórmula dada pela professora

Instruções
1 - Informar o nome do aparelho
2 - Informar a potência
3 - informar o tempo de uso por dia
